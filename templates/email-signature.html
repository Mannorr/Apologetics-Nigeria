How to install

Use Copy signature (not the HTML source) for all three clients below — it copies the rendered version, which is what these settings panels expect.

Gmail, Outlook and Apple Mail
  1. Gmail: Settings → See all settings → General → Signature → Create new, then paste. Set it as the default for new emails and replies, and Save Changes at the bottom.
  2. Outlook (web): Settings → Mail → Compose and reply → Email signature, then paste and save.
  3. Outlook (desktop): File → Options → Mail → Signatures, then paste. Outlook strips some styling — check it renders before sending.
  4. Apple Mail: Settings → Signatures, then paste and untick “Always match my default message font.”
